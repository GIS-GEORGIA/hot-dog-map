# 🌭 Hot Dog Map

ორენოვანი (ქარ/ინგ), მუქი/ნათელი თემის PWA რუკა Google My Maps-ის მონაცემებზე დაფუძნებული.

## გაშვება

```
npm install
npm run kml2geojson   # data/*.kml → data/locations.geojson
npm run dev
```

## Build & Deploy

`main`-ში push ავტომატურად აბილდავს და აქვეყნებს GitHub Pages-ზე (`.github/workflows/deploy.yml`).

დეტალებისთვის იხილე [data/README.md](data/README.md).
