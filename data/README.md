# მონაცემები

1. ჩააგდე შენი KML/KMZ ფაილი აქ (`data/*.kml`). KMZ-ს ჯერ ამოაარქივე (`unzip file.kmz -d data/` და გადაარქვი `doc.kml`-ს).
2. გაუშვი: `npm run kml2geojson`
3. მიიღებ `data/locations.geojson`-ს, კატეგორიები აღებულია Google My Maps ფენების (Folder) სახელებიდან.
4. `title_en`, `description_en`, `image_url` ველები ცარიელი გამოვა — შეავსე საჭიროებისამებრ ხელით.
